## 3️⃣ FILTERS

⚠️ Copy this block for each filter you want:

<Filter
  type="_______"           // multiselect | singleselect | daterange
  label="_______"          // Display name
  field="_______"          // Exact CSV column name
  placeholder="_______"    // (optional) Placeholder text
  dataSources={['_______']} // Which data source(s) - use exact fetch names from #1
  options={['_______']}    // Only for singleselect (include 'all' as first option)
/>

--------------------------------------------------------------------------------

Filter Types:
- multiselect - Multiple checkboxes, auto-populated from data
- singleselect - Radio buttons, requires static options array
- daterange - Date range picker for timestamp fields

--------------------------------------------------------------------------------

📝 EXAMPLE:

<Filter
  type="multiselect"
  label="Genres"
  field="genre"
  placeholder="Select genres"
  dataSources={['readingBooks', 'readingSessions']}
/>

<Filter
  type="singleselect"
  label="Fiction/Non-Fiction"
  field="fiction_yn"
  defaultValue="all"
  dataSources={['readingBooks']}
  options={['all', 'Fiction', 'Non-Fiction']}
/>

## 4️⃣ KPI CARDS

⚠️ Copy this block for each statistic card:

<KpiCard
  dataSource="_______"              // Which data source (from #1)
  field="_______"                   // CSV column name (omit for 'count')
  computation="_______"             // count | sum | average | median | min | max
  computationOptions={{ decimals: _, filterZeros: true }}  // (optional)
  label="_______"                   // Display text with unit if needed
/>

--------------------------------------------------------------------------------

Computation Types:
- count - Count items (no field needed)
- sum - Sum numeric values
- average - Mean (use filterZeros: true to exclude zeros)
- median, min, max - Self-explanatory

--------------------------------------------------------------------------------

📝 EXAMPLE:

<KpiCard
  dataSource="readingBooks"
  computation="count"
  label="Books Read"
/>

<KpiCard
  dataSource="readingBooks"
  field="my_rating"
  computation="average"
  computationOptions={{ decimals: 1, filterZeros: true }}
  label="Average Rating"
/>

## 7️⃣ ANALYSIS CHARTS

⚠️ Copy this block for each chart:

<[ChartType]
  data={filtered_______}            // Usually secondary data source
  dateColumnName="_______"          // Timestamp column name
  metricColumnName="_______"        // OR valueColumnName for value to aggregate
  title="_______"                   // Chart title
  yAxisLabel="_______"              // (for bar/line charts) Unit label
  [specificProp]="_______"          // Chart-specific options
/>

--------------------------------------------------------------------------------

Available Chart Types:
- TimeSeriesBarChart - Trends over time (daily/weekly/monthly auto-aggregation)
- IntensityHeatmap - Day × hour activity heatmap (prop: treatMidnightAsUnknown: true/false)
- TopChart - Top N items bar chart
- TreemapChart - Hierarchical categories
- PieChart - Distribution pie chart
- ScatterPlot - Two-variable correlation

--------------------------------------------------------------------------------

📝 EXAMPLE:

<TimeSeriesBarChart
  data={filteredReadingEntries}
  dateColumnName="timestamp"
  metricColumnName="page_split"
  title="Total Pages Read by Period"
  yAxisLabel="Pages"
/>

<IntensityHeatmap
  data={filteredReadingEntries}
  dateColumnName="timestamp"
  valueColumnName="page_split"
  title="Reading Activity by Day and Time"
  treatMidnightAsUnknown={true}
/>
